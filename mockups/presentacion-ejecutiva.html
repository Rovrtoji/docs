ERP / CRM corporativo

Una plataforma única que reemplaza el ERP legacy (Odoo 17) por un stack moderno: aplicaciones web en React, un backend FastAPI sobre PostgreSQL y servicios independientes para facturación, asistencia y monitoreo GPS.

01Qué es

El sistema operativo de la empresa de rastreo y soluciones GPS B2B.

Negocio

Operación 360°

Clientes, instalaciones, soporte, inventario, finanzas y monitoreo GPS en una sola plataforma, con datos compartidos y trazables.

Tecnología

Stack moderno

Frontend React + Vite (monorepo), backend FastAPI asíncrono, PostgreSQL, Redis y almacenamiento S3. Despliegue en Docker / Dokploy.

Estrategia

Salida de Odoo

Migración progresiva del legacy Odoo 17 a código propio, sin licencias de terceros y con control total de la evolución del producto.

02Arquitectura

Apps web independientes, un backend central y servicios satélite que comparten la misma base de datos.

03Aplicaciones

Seis frontends en el monorepo más dos portales especializados, con un acceso unificado (Hub estilo Odoo).

Acceso

Hub

Punto de entrada único: login, launcher de aplicaciones y handoff seguro de sesión hacia cada app.

Administración

Backoffice

RBAC, usuarios, roles, catálogos, micrositios, auditoría y notificaciones in-app.

Finanzas

Finanzas Web

Ingresos, facturación, cuentas, proveedores, reportes y dashboards financieros.

Operación

Operaciones Web

Órdenes de trabajo, instalaciones, inventario y evidencias de campo.

Comercial

CRM Web

Gestión de clientes, contactos y relación comercial.

Personas

RH Web

Empleados, horarios y la base de Recursos Humanos.

Móvil/Web

Checador

Registro de asistencia con geolocalización e idempotencia; app separada con su propio backend.

Externo

Portal Cliente

Soporte GPS multi-tenant para el cliente final: flota, solicitudes, evidencias y notificaciones.

04Servicios independientes

Procesos desacoplados del backend principal; comparten solo la base de datos.

Facturación

AlegraPy

Sincroniza las facturas de la API de Alegra hacia PostgreSQL todos los días a las 3:00 AM (CDMX). Reemplazó el viejo sync por MongoDB; corre en su propio contenedor.

Asistencia

Checador

Registro de entradas/salidas con foto y ubicación. Backend propio, idempotencia por Idempotency-Key y almacenamiento de evidencias en S3.

Monitoreo

Central de Monitoreo

Monitoreo GPS B2B (preventivo, reactivo, cámaras) e integración con Centinela/ANERPV vía el wialon-bridge. 15 tablas propias.

07Seguridad y calidad

Autenticación

  • Cookie httpOnly + CSRF double-submit en todo el frontend (sin tokens en localStorage).
  • Handoff de sesión entre apps: token SHA-256, un solo uso, TTL 60 s, ligado a IP/UA.
  • RBAC por roles y aplicaciones, con auditoría de acciones sensibles.

Trazabilidad

  • Audit log de creación/edición/borrado en RBAC, usuarios, catálogos y aplicaciones.
  • Notificaciones automáticas a administradores ante eventos de seguridad.
  • OpenAPI 3.1 generado del código real: la documentación nunca se desincroniza.
