## Cómo consumir esta API

- **Base URL:** `https://portal.<dominio>` (prod) o `http://localhost:8000` (local)
- **Prefijo:** todos los endpoints viven bajo `/api/v1`
- **Autenticación:** JWT por header `Authorization: Bearer <token>` obtenido vía `POST /api/v1/auth/login`. **No** se usan cookies httpOnly (a diferencia del ERP `finananzaspython`)
- **Multi-tenant:** todos los endpoints filtran por `tenant_id` derivado del token. Acceder a recursos de otro tenant devuelve **404** (no 403, para no filtrar existencia)

<Warning>
  El portal y el ERP son backends **separados** con autenticación diferente:
  - **ERP** (`finananzaspython`): cookie httpOnly + CSRF double-submit
  - **Portal** (`soportecliente`): JWT Bearer
</Warning>
