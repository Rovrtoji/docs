**Goal:** Integrar AlegraPy como servicio independiente (contenedor propio) que sincroniza facturas de la API de Alegra a PostgreSQL a las 3:00 AM CDMX, sin tocar el runtime del backend principal.

**Architecture:** AlegraPy vive en `services/alegrapy/` dentro del repo backend pero corre como contenedor separado en `dokploy-network`. Lee de la API de Alegra (no Mongo), escribe a la tabla `invoices` de la misma BD del backend. Scheduler interno mejorado con hora fija (`CRON_AT_HOUR=3` + timezone `America/Mexico_City`).

**Tech Stack:** Python 3.12, httpx, asyncpg, pydantic v2, Docker, Dokploy. Spec: `docs/superpowers/specs/2026-06-05-integracion-alegrapy-design.md`.

```python
def _next_run_at_fixed_hour(
    hour: int, tz_name: str, now: datetime | None = None
) -> datetime:
    """Devuelve el proximo instante (en UTC) cuando den las hour:00 en tz_name.

    Si la hora objetivo ya paso hoy en esa timezone, devuelve la de manana.
    """
    tz = ZoneInfo(tz_name)
    now_local = (now or datetime.now(UTC)).astimezone(tz)
    target = now_local.replace(hour=hour, minute=0, second=0, microsecond=0)
    if target <= now_local:
        target = target + timedelta(days=1)
    return target.astimezone(UTC)
```

            )
        else:

        )

# Servicio AlegraPy para Dokploy. Worker de sync (no recibe trafico HTTP).

# Variables a configurar en la UI de Dokploy:

      - dokploy-network
    environment:
      EMPRESA_1_NOMBRE: ${EMPRESA_1_NOMBRE}
      ALEGRA_USER_1: ${ALEGRA_USER_1}
      ALEGRA_KEY_1: ${ALEGRA_KEY_1}

      CRON_ENABLED: ${CRON_ENABLED:-true}
      CRON_AT_HOUR: ${CRON_AT_HOUR:-3}

## Deploy (Dokploy)

1. Crear servicio apuntando a `services/alegrapy/` (compose).
2. Configurar las variables de arriba en la UI.
3. Desplegar. El contenedor queda residente y dispara el sync a las 3 AM CDMX.

## Cómo se programa el 3 AM

`CRON_ENABLED=true` + `CRON_AT_HOUR=3` + `TZ_CRON=America/Mexico_City`: el
scheduler calcula el próximo `03:00` CDMX y duerme hasta ahí. Persiste el estado
en la tabla `sync_state` (la crea automáticamente). Si el contenedor reinicia,
recalcula el próximo 3 AM (no se desfasa).
