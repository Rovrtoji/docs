## Cómo consumir esta API

- **Base URL:** `https://api.<dominio>` o local `http://localhost:8090` / `:8091`
- **Prefijo:** todos los endpoints viven bajo `/api/v1`
- **Autenticación:** cookie httpOnly + CSRF double-submit (`X-CSRF-Token` en POST/PUT/PATCH/DELETE)
- **OpenAPI live:** `GET /docs` (Swagger UI) y `GET /openapi.json` (spec completo con schemas)
